# JFL Builder GUI 文档

## 概述
`JFL_builder_GUI.py` 是一个使用 Python 的 `tkinter` 库构建的桌面应用程序。它提供了一个图形用户界面，用于设计轴对称接触镜并生成相应的 JFL 文件。与 Streamlit 应用不同，这是一个独立的桌面 GUI 程序。

## 功能特性
*   **桌面 GUI 界面**：使用 `tkinter` 和 `ttk` 构建，具有原生桌面应用体验。
*   **镜片参数输入**：
    *   允许配置镜片中心厚度和加工直径。
    *   根据输入的直径动态更新镜片半口径。
*   **多表面设计**：
    *   使用标签页界面独立管理 `前表面`、`后表面` 和 `边缘` 参数。
    *   可配置每个表面的起始坐标 (X, Z)。
    *   支持每个表面包含多个弧段。
*   **动态弧段管理**：
    *   用户可以指定弧段的数量。
    *   UI 会根据数量动态更新，显示每个弧段的参数输入框。
*   **面型支持**：支持 `Standard` (标准面)、`EvenAsphere` (偶次非球面)、`OffsetCircle` (离轴球面) 和 `Line` (直线)。
*   **实时可视化**：将 `matplotlib` 图表直接嵌入 `tkinter` 窗口中，显示镜片轮廓。
*   **文件操作**：
    *   **生成并绘图**：触发计算和渲染的按钮。
    *   **下载 JFL 文件**：将设计保存为 `.JFL` 文件。
    *   **下载参数 JSON 文件**：将设计参数保存为 `.json` 文件。

## 使用方法
1.  **启动应用**：
    ```bash
    python JFL_builder_GUI.py
    ```
2.  **配置镜片**：在左上角区域输入 `镜片中心厚度` 和 `加工直径`。
3.  **设计表面**：
    *   选择一个标签页（例如 "前表面"）。
    *   输入起始 X/Z 坐标。
    *   设置 `弧段数`。
    *   对于出现的每个弧段，选择 `面型` 并填写所需的参数（曲率半径、Conic系数、半口径等）。
4.  **可视化**：点击 "生成并绘图" 按钮。镜片轮廓将显示在右侧面板中。
5.  **保存**：
    *   使用 "下载JFL文件" 导出加工文件。
    *   使用 "下载参数JSON文件" 保存配置。

## 代码结构
*   **`LensGeneratorApp` 类**：继承自 `tk.Tk` 的主类。
    *   `__init__`：设置主窗口并初始化变量。
    *   `create_widgets`：布局左侧（输入）和右侧（绘图）框架。
    *   `create_input_frame`：填充输入字段和笔记本标签页。
    *   `create_surface_tab`：为每个表面创建标签页。
    *   `update_segments`：根据用户输入的数量动态添加/删除弧段输入框架。
    *   `generate_and_plot`：读取所有输入，执行矢高计算（使用内部逻辑或导入的函数），并更新 matplotlib 画布。
*   **辅助函数**：
    *   包含矢高计算的实现（如 `standard_sag` 等），模拟了 `sag_calculator.py` 中的逻辑。
    *   `plot_jfl_segments_with_arrows`：处理 matplotlib 绘图逻辑。

## 依赖项
*   `tkinter` (Python 标准库)
*   `numpy`
*   `matplotlib`
