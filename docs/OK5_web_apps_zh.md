# OK5 Web 工具文档

## 概述
OK5 Web 工具是一套基于 HTML/JavaScript 的应用程序，用于设计角膜塑形镜 (Ortho-K) 和 RGP 镜片。这些工具直接在浏览器中运行，为镜片设计的不同方面提供了专门的界面。

## 工具汇总

### 1. `OK5_intergrated.html` (核心工具)
这是功能最全面的版本，集成了设计计算、公式锁定和高级可视化功能。

*   **主要功能**：
    *   **全面输入网格**：提供 FlatK, ecc, TP, Jessen, BOD, lensD, RCwidth, 和 edgeLift 等参数输入。
    *   **公式驱动设计**：
        *   **曲率公式**：使用 `math.js` 解析的可编辑公式，用于计算 BC, AC1, AC2, RC, 和 PC 曲线。
        *   **直径公式**：可编辑公式，用于计算每个区域的终点直径。
    *   **锁定机制**：
        *   `Lock Formula` (锁定公式)：强制曲率半径跟随公式计算值。
        *   `Lock AC2R` (锁定 AC2R)：保持 AC2R 和 AC1R 之间的差值固定。
        *   `Lock Seg Formula` (锁定直径公式)：强制弧段直径跟随公式计算值。
    *   **双显示模式**：在半径 (mm) 和光焦度 (Diopters) 之间切换。
    *   **高级可视化**：
        *   **荧光图 (Fluorescein Plot)**：基于泪膜厚度模拟荧光素模式。
        *   **泪膜图 (Tear Film Plot)**：显示泪膜剖面。
        *   **矢高图 (Sag Plot)**：显示镜片和角膜的矢高剖面。
    *   **导入/导出**：通过 CSV 文件保存和加载镜片设计。

### 2. `OK5_design.html` & `OK5_design_DK.html`
这些是专注于特定设计范式的变体版本。`OK5_design_DK.html` 可能包含与 "DK" (可能是 Defocus 离焦或 Dual Curve 双弧?) 参数相关的特定调整或设计逻辑变化。

*   **通用功能**：
    *   标准镜片参数输入框。
    *   用于选择计算方法的单选按钮 (例如：RCR 的数值求解 vs 简单计算)。
    *   用于荧光素、泪液和组合图的可视化画布。

### 3. `OK5_tutorial.html`
这是一个简化版本，旨在用于教学目的或基本参数计算，去除了集成工具中复杂的交互和部分可视化开销。

## 技术细节 (OK5_intergrated.html)

### 依赖库
*   **Math.js**: 用于安全灵活地解析用户定义的曲率和直径公式。

### 核心逻辑
1.  **输入采集**：从 DOM 读取所有数值输入。
2.  **公式求值**：
    *   解析公式输入框中的字符串。
    *   根据当前输入参数 (FlatK, ecc 等) 对其进行求值。
    *   更新内部数据属性 (`dataset.backend`) 以存储精确数值。
3.  **矢高 (Sag) 计算**：
    *   使用标准的非球面矢高方程：
        $$Z(x) = \frac{x^2}{R(1+\sqrt{1-(1+k)\frac{x^2}{R^2}})}$$
    *   计算角膜和多区段镜片的矢高。
    *   计算泪膜厚度 (角膜矢高与镜片矢高之差)。
4.  **渲染**：
    *   使用 Canvas API 绘制剖面图和模拟荧光素模式。
    *   荧光素模式使用基于 Beer-Lambert 定律的颜色映射模型，根据泪液厚度模拟亮度强度。

## 使用指南 (集成工具)
1.  **打开 HTML 文件**：在现代 Web 浏览器中打开文件。
2.  **设置基础参数**：输入 `FlatK`, `ecc`, `TP` 等数值。
3.  **编辑公式** (可选)：如果需要自定义逻辑，修改曲线或直径的数学表达式。
4.  **查看结果**：在结果网格中检查计算出的半径和直径。
5.  **分析图表**：利用右侧的三个图表 (矢高、泪液层、荧光图) 验证配适情况。
6.  **导出**：使用 "Export Config" (导出配置) 按钮保存您的工作。
